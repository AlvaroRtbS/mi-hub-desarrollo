# App móvil (Expo)

**Estado:** placeholder. Se monta en el **Sprint 5** del plan, cuando la web esté funcionando.

## Plan

- **Expo (React Native)** — un solo código para iOS y Android.
- Reusará los tipos y la conexión a Supabase del paquete `web/src/lib/supabase`.
- Pantallas mínimas para la clienta:
  1. Login
  2. "Hoy entreno" — ejercicios del día, marcar series con pesos.
  3. Mediciones — peso, perímetros, fotos.
  4. Pasos — sincronización automática con Apple Health / Google Fit (sin captura de pantalla).
  5. Nutrición — ver planes y marcar lista de la compra.
  6. Mensajes — chat con la entrenadora.
- Notificaciones push (Expo Notifications) para recordatorios de entreno.

## Cuándo

Cuando hayamos validado en web con las clientas reales que la migración está completa y todo funciona.
